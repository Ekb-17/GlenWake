# GlenWake development instructions

Read PROJECT_PLAN.md and README.md before changing this project.

The current application implements milestone 1 only. Implement later features in bounded, tested stages and update the plan with evidence and limitations after each stage.

Never present planned or experimental AI capabilities as already working. Do not invent model results, confidence, coverage percentages, or accuracy. Keep manual observations, model predictions, and calculated measurements distinct. Preserve evidence and report uncertainty.

For code changes, run the backend tests and frontend build documented in README.md, plus relevant tests for changed behavior. Record checks actually run and their results; a build is not an AI evaluation. Keep local recordings and databases out of Git.

Write repository documentation in a professional, project-focused style. Omit editorial update dates, conversation summaries, private source-file references, and narration about the user or assistant. Preserve technical evidence timestamps, reproducible validation details, and clear implementation limits.
